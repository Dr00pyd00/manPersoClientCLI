
# CLI for ManPerso 

This is client for the `manPersoServer`.  
The system is a perso `man` with client-server-postgresql application.  


## Installation 

```bash 

git clone ~/

``` 

## How to use 

```
usage: main.py [-h] [-l] [-t TAGS] [-c] [title]

positional arguments:
  title            Display a detail page by
                   title

options:
  -h, --help       show this help message and
                   exit
  -l, --list       Display all manpage
  -t, --tags TAGS  Filer for tag during --list
  -c, --create     Open vim for create new page
```
